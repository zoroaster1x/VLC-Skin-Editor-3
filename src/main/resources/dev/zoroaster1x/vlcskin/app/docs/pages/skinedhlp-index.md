# VLC Skin Editor - Online Help

Welcome to the online help to the VLC Skin Editor.

Here you will find help regarding the different elements of a skin and how to use the different features of the Skin Editor.

If you encounter a problem in the usage of the Skin Editor or if you have a question that is not answered here, please turn to the [skins section](https://forum.videolan.org/viewforum.php?f=15) of the VideoLAN Forums.

Please note that this page is currently under construction.
