FreeSans.ttf
============

VLC's skins2 "defaultfont" is FreeSans, loaded from its resource path
(modules/gui/skins2/parser/builder.cpp:1211-1226). This is a copy of
share/skins2/fonts/FreeSans.ttf from VLC 4.0.0-dev (revision
e77e49b5dff7484dbf70cd1540a6a568e1890280), so the studio renders default-font
text with the same typeface metrics as VLC instead of a platform font.

Source: https://github.com/videolan/vlc/blob/e77e49b5dff7484dbf70cd1540a6a568e1890280/share/skins2/fonts/FreeSans.ttf
